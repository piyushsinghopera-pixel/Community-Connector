# communityconnector

This is a Next.js project bootstrapped with v0.app

we built CommunityConnector on top of this - a platform where citizens can report local issues like garbage, broken streetlights, water leakage, potholes with photo + video and it shows on real Google Maps.

## Built with v0

this repo is linked to v0 project. whatever we build in v0 chat, it auto pushes commits here. and every merge to main auto deploys.

[Continue working on v0 →](https://v0.app/chat/projects/prj_zuIzER1hiqw8jIau92gCdD9MN5A2)

super easy, just 2 commands. we use pnpm btw not npm.

```bash
pnpm install
pnpm dev
